% \citep{Torres-Irineo2021-pq} used Generalized Linear/Additive/Boosting Models (GLM, GAM, GBM, respectively), Classification Tree Analysis (CTA), Artificial Neural Network (ANN), Surface Range Envelope (SRE), Flexible Discriminant Analysis (FDA), Multiple Adaptive Regression Splines (MARS), and RF to build species distribution models (not the same as actual grounds).

Previous work set defensible but arbitrarily chosen thresholds on the spatial resolution for the identification of fishing grounds. For example, X did A and Y did B. The same is true for temporal thresholds, where a specific number of hours are required for the activity within a grid cell to count. My method differs in a few ways. First, the spatial scale is determined by the data themselves and are a product of the time required for a fishing ground to count as such. Second, because the size of a fishing ground depends on utilization intensity rather than fixed by the researcher, it is possible to perform robustness checks to determine how the chosen utilization density affects it. And, finally, because the utilization density can be easily identified with a simple question posed to fishers: ``\textit{When you go out to fish, how much time do you spend in a given place before relocating or coming back to port?}``
